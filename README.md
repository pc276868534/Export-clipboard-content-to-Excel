# 微信统计信息监控器

一个用于监控剪贴板并自动提取微信统计消息的GUI工具。

## 功能特点

- ✅ **Excel数据读取** - 读取现有Excel文件并检测内部重复
- ✅ **行级别检测** - 只处理与"统计"在同一行的完整内容
- ✅ **实时监控剪贴板** - 自动检测剪贴板内容变化
- ✅ **严格格式识别** - 只处理严格以"统计"开头的消息
- ✅ **智能重复检测** - Excel内重复+新数据重复，双重检测
- ✅ **自动解析数据** - 提取名字、位置、租金、租期、押金方式等信息
- ✅ **追加导出Excel** - 保留原Excel数据，追加新数据到末尾
- ✅ **实时显示** - 显示历史记录和解析结果
- ✅ **数据管理** - 支持删除、刷新等操作

## 支持的消息格式

**行级别检测：只处理与"统计"在同一行的完整内容**

```
这是普通消息
统计，名字，位置，租金，租期，押金方式
这也是普通消息
```

示例：
```
这是其他聊天内容
统计，张三，深圳福田公寓，1500元，24个月，押二付一
统计，李四，深圳南山写字楼，2000元，12个月，押一付三
普通聊天消息，不会被处理
```

**行级别处理特点：**
- 📄 复制多行内容时，逐行检测"统计"关键字
- 🎯 只提取包含"统计"的完整行
- ⏭️ 自动跳过不包含"统计"的行
- 📊 支持一次复制多条统计消息

**有效格式：**
- `统计，张三，位置，租金，租期，押金方式` ✅
- `统计,张三,位置,租金,租期,押金方式` ✅  
- `统计：张三：位置：租金：租期：押金方式` ✅
- `统计 张三 位置 租金 租期 押金方式` ✅

**无效格式：**
- `前缀统计，张三，位置，租金，租期，押金方式` ❌
- `普通消息，张三，位置，租金，租期，押金方式` ❌
- `张三，位置，租金，租期，押金方式` ❌

## Excel数据管理

### 读取现有Excel
- **加载功能：** 点击"读取Excel"按钮加载现有数据
- **重复检测：** 自动检测Excel内部的重复记录
- **合并显示：** Excel数据和新数据一起显示在界面中
- **去重基础：** Excel数据加入重复检测池

### 追加导出
- **保留原数据：** 导出时保留Excel中的原有数据
- **追加新数据：** 将新数据追加到Excel文件末尾
- **统计报告：** 显示原有数据、新数据、总计数量

## 重复数据检测

### 多层检测机制
1. **Excel内重复：** 读取时检测并标记Excel文件内的重复
2. **新数据重复：** 监控时检测新数据的重复
3. **跨文件重复：** 新数据与Excel现有数据比较
4. **用户确认：** 发现重复时弹出确认对话框

### 检测依据
- **核心字段：** 名字、位置、租金、租期、押金方式
- **签名机制：** 生成唯一标识进行快速比较
- **用户选择：** 可选择是否添加重复记录
- **标记功能：** 重复记录会标记特殊备注

## 安装和使用

### 1. 安装依赖库

```bash
pip install pyperclip pandas openpyxl
```

或者使用requirements.txt：
```bash
pip install -r requirements.txt
```

### 2. 运行程序

方法一：使用启动脚本
```bash
python run_monitor.py
```

方法二：直接运行GUI
```bash
python wetchat_GUI.py
```

## 使用步骤

### 📋 推荐工作流程：

1. **读取现有数据** - 点击"读取Excel"按钮加载现有Excel文件

2. **开始监控** - 点击"开始监控"按钮启动剪贴板监控

3. **复制微信内容** - 从微信复制聊天内容（可一次复制多行）

4. **自动提取** - 程序自动提取与"统计"同一行的内容

5. **去重检测** - 检测Excel内重复和新数据重复，弹出确认

6. **查看结果** - 在"解析结果"标签页查看合并后的数据

7. **追加导出** - 点击"导出到Excel"将新数据追加到Excel末尾

### 💡 使用技巧：

- **批量处理：** 一次复制多行聊天内容，程序自动提取统计行
- **先读后监：** 建议先读取Excel数据，再开始监控，避免重复
- **多行监控：** 支持复制包含多个统计消息的文本块
- **智能提示：** 重复检测会显示详细的重复信息供确认
- **数据安全：** 导出采用追加模式，不会丢失原有数据

## 界面功能说明

### 控制面板
- **Excel文件**：设置导出的Excel文件路径
- **读取Excel**：读取现有Excel文件并显示在预览窗口
- **开始/停止监控**：控制剪贴板监控的启停
- **立即检查剪贴板**：手动检查当前剪贴板（行级别检测）
- **清空历史**：清除所有记录、Excel缓存和重复检测

### 监控状态
- 显示当前监控状态和最后更新时间
- 实时进度条显示监控活动

### 剪贴板历史
- 显示最近的剪贴板内容
- **行级别高亮**：检测剪贴板中的统计行并高亮
- **统计预览**：显示每条统计消息的行号和内容预览
- **智能标识**：普通消息和统计消息用不同图标区分
- 自动限制显示最近20条记录

### 解析结果
- **合并显示**：Excel数据和新数据一起显示在表格中
- **数据来源**：标识每条记录来自Excel或剪贴板
- **完整信息**：包含序号、名字、位置、租金、租期、押金方式、时间、备注
- **智能编号**：自动重新编号，序号连续
- 支持选择删除操作

### 操作按钮
- **导出到Excel**：将解析数据保存到Excel文件
- **打开Excel文件**：直接打开Excel文件查看
- **删除选中记录**：删除选中的数据行
- **刷新数据**：重新加载数据显示
- **使用说明**：查看详细使用说明

## 注意事项
